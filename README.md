<h1>Enterprise Network Lab Fortigate NLAB</h1>

<p>
Simulated enterprise network with two sites (Hub & Spoke), focused on routing, VPN, NAT and network segmentation.
</p>

<p>
Core topics: VLANs, BGP, IPsec VPN, NAT (SNAT/DNAT), SD-WAN basics
</p>

<h2>Overview</h2>

<ul>
<li>Two-site architecture (Hub & Spoke)</li>
<li>/16 network segmentation with multiple VLANs</li>
<li>Different firewall deployment strategies</li>
<li>Routing, NAT and DNS implementation</li>
</ul>

<h2>Technologies</h2>

<ul>
<li>FortiGate (Firewall & VPN)</li>
<li>BGP (Dynamic Routing)</li>
<li>IPsec (Site-to-Site & Remote Access)</li>
<li>VLAN & Switching</li>
<li>NAT (SNAT / DNAT)</li>
</ul>

<h2>Network Design</h2>

<ul>
<li>LAN (private networks)</li>
<li>WAN (simulated public ranges)</li>
<li>DMZ</li>
<li>VPN tunnels</li>
<li>VLAN segmentation (Clients, Admins, Servers, Guest, Printer)</li>
</ul>

<h2>Key Features</h2>

<ul>
<li>Site-to-Site VPN (Hub-to-Spoke)</li>
<li>Overlapping Subnet VPN with NAT</li>
<li>Remote Access VPN (IKEv2)</li>
<li>BGP routing with route advertisement</li>
<li>Dual-WAN & SD-WAN concepts</li>
</ul>

<h2>Troubleshooting & Learning</h2>

<ul>
<li>
Strong focus on real troubleshooting scenarios:
</li>
<ul>
<li>VPN tunnel failures (NAT / policy issues)</li>
<li>BGP route propagation problems</li>
<li>SNAT / DNAT misconfigurations</li>
</ul>

<li>
Key takeaway:
<br>
<em>"It's always NAT, Routing or DNS."</em>
</li>
</ul>
